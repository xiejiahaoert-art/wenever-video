# 渲染、配乐和验收

## 画面实现

- 从原片探测得到 9:16 后，用 1080×1920 或等比画布。用户要求另一比例时重新摆位，保持文本、头部、关节、圆形和按钮的几何。画面在某个比例里更松散时优先改道具位置和人物活动区。
- 简笔动效适合 Canvas、SVG、Remotion 或已验证的逐帧渲染工具。以时间参数求每帧的状态，避免依赖实时定时器。样片至少包含一个完整动作、一次转场和一种可核验的数值变化。
- [火柴人参考实现](../assets/stick-figure.mjs) 接收 Canvas 2D 上下文，`y` 是地面高度，`look` 用 `1` 或 `-1` 表示朝向。`target` 与 `otherTarget` 是场景坐标中的前手和另一只手的接触点，`reach` 与 `otherReach` 控制接触进度。`sit` 从 0 到 1 插值站姿和坐姿。沿用画布安全区和遮挡顺序，角色可用小领结保持跨镜一致。
- 按时间映射重渲时用 [时间映射模块](../assets/timing.mjs)。锚点是 `[成片秒, 原动画秒]`。用 `window.getFrame(t)` 之类的入口求 `makeTimeMap(anchors).sourceTimeAt(t)`，按帧输出。音效原始事件可用逆映射重新放置。拍点优先服务于关键动作，避免整片强行追每拍。

### 动态封面与第一镜接续

- 修已有成片的开场时先取正文第一镜。试着把吸睛标题放在原场景的纸面、屏幕或留白里，保持构图、主物件和镜头方向。字幕和第一句口播在同一镜内进入，让悬念自然交给正文。
- 接缝明显时分别检查画面、文字和声音。可用正文起始帧做结尾对照，去掉造成二次开场的翻页、闪白或音效，保持配乐乐句和音量连续。验片时抽接缝前、中、后帧，检查背景位置、亮度和标题是否重复出现，再连播开头与第一句。
- 中文标题优先用可控字体图层。在手机宽度下看首帧及标题完成帧，检查字号、边缘、对比和遮挡。字压在笔记本的透视边或亮处时，把整行移入稳定的可读区域。

### 火柴人四肢与道具

- 站姿收近脚距，脚尖大致顺着身体朝向，空手垂在躯干附近。站定时重心的变化由髋、膝和肩来表现，支撑脚留在原处。走动时随步伐放宽脚距和摆臂，停下后回到放松站姿。
- 坐姿先定位椅面和地面，再让髋部落到椅面附近，膝盖朝桌面，脚落地。弯腰拉抽屉或按键时，先动肩和髋，再屈肘屈膝。庆祝跳跃可用一手举拳、一手收近胸口，落地以屈膝减震。
- 拿放道具先定好接触点。递卡时两人的手分别抓卡片两侧，卡片停在胸口或桌沿，给低头和点头留出空间。依次抽查接触前、接触时、放手后的帧，再检查脸、文字、道具和手是否互相挡住。
- 只修四肢时先用旧版和新版同时间对照站、坐、递卡、按键、起跳和落地，再检查各关键动作的接触帧。沿用原镜头边界、字幕和音效时间。可直接复用成片音轨的项目可用 `-c:a copy` 保留原混音，并核对导出前后的音轨校验值。

## 配音、音轨和卡点

1. 用 FFmpeg 从用户提供或授权的音源提取分析轨。选段落边界、能量起落和实际音乐重拍。允许粗估拍间隔，再抽查是否把半拍或双倍 BPM 当成主拍。混入音效或说话时观察局部峰值。
2. 先锁开场、核心机制、转折、片名出现和尾声，再分别加速等待段、放慢关键信息段。已有成片无源工程时可用 FFmpeg 按完整动作分段处理后拼接。口播决定节奏时要同步编辑语音，有声素材变速时优先保持音高，并重核字幕。
3. 无旁白视频用静音预览确认内容，开声确认落位、报错、盖章、传输和转场的时点。需要普通话时，用正式稿最难读的 15–20 秒测可用音色；术语、人名、数字、重音和停顿都听一遍。MiniMax 等引擎的入口可用和指定音色已实测是两件事。有读音词典时按词典处理，分段生成并用最终音轨对齐字幕。
4. 片尾让最后一个画面落在乐句上，视频和音乐同期淡出。片名要在音乐变弱时仍可看见。缺指定配乐时明确交付的是画面和音效版，保留未来合成所需的节奏和源工程。

### 已有画面接用户录音

- 转写录音并和当前稿逐段核对。原稿改动时先确认这份录音实际读了哪一版。录音和原时间线长度不同，优先用语句起点、停顿和关键词建立锚点，硬字幕与画面按同一时间映射调整。
- 从用户指定音乐找两处或少数自然起势，贴到叙事变化或关键词。保留曲子的乐句，按人声平滑压低和释放配乐。新增开场可提前铺入同一条音乐，接入正文时避免再次淡入。验片同时抽查首句、关键字幕、音乐峰值与片尾是否齐。
- 需要给卡片、点击或触碰配音效时，先做动作与声音的对照表，再按材质选声、在原画上试听。调用 Freesound 的公开工具及 A/B 做法见 [动作音效与 Sound Skill](sound-skill.md)。

## 可运行工具

以下命令在 Skill 根目录执行。Python 3.10+，`ffmpeg` 和 `ffprobe` 需要在 PATH。拍点脚本额外需要 NumPy。文件名用引号包住。

```sh
python scripts/media.py inspect "input.mp4"
python scripts/beat_grid.py "input.mp4" --start 5 --end 83
python scripts/media.py mux "picture.mp4" "input.mp4" "synced.mp4" --fade 1.6
python scripts/media.py inspect "synced.mp4" --require-clean
```

- `inspect` 解码整段，返回视频与音频时长、显示比例、帧率和黑段。默认标记持续 0.6 秒以上、98.5% 像素低于亮度阈值的片段。极暗风格可能误报，检查实际帧。可调阈值，片尾以最后可读帧、人耳和音轨长度一起验收。
- `beat_grid.py` 回传估算 BPM、等距网格以及每拍附近的瞬态峰值。用峰值选点后再看画面和听音乐。非恒速音乐分段分析。计算结果不等同于小节重拍。
- `mux` 直接复制已切好、可封装为 MP4 的视频流，用指定文件的第一条音轨，短于画面时补静音，长于画面时裁齐，最后按指定秒数淡出。准备完成的混合音可作输入。此命令只用于换入音轨，不会自动把原音叠上去。
- 最后另外核对三秒钩子、动作接触、关键转场、公式与代码安全区，以及最后几帧确实仍与音乐结束点对齐。完整解码成功说明文件可解码，画面和声画关系需另外检查。

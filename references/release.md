# 发布文案与封面

从最终成片和用户指定的平台、比例出发。只有标题、话题、描述或封面的需求时，直接在现有视频基础上交付这些材料。

## 多平台文案

1. 先核对最终片名、口播、结果画面和片尾。将标题的承诺落到片中能定位的内容。区分场景演示、实际操作和有来源的比较结果。剧本里删掉的下集预告或承诺也从发布稿中移除。
2. 按各平台的实际发布字段写出可单独粘贴的标题、描述和候选话题。字段、字符限制、标识入口或画幅要求有影响时，核对当前官方说明或发布页。把关键词、篇幅和话题数量作为编辑取舍。
3. 话题从实际工具、任务与受众选。动画含 AI 生成画面时，发布时用平台的声明功能如实标识相应内容。发布同一条带背景音乐的成片到多个平台前，核对音源在对应平台和用途中的授权。将这些发布设置与可复制正文分开放。 [生成合成内容标识办法](https://www.nrta.gov.cn/art/2025/3/14/art_113_70340.html)

| 指定平台 | 《手上这件活，该找哪个 AI？》的写法 |
| --- | --- |
| 抖音 | 用交活的具体处境起题，短描述给三种选法和片尾速查表。话题贴工具和办公任务。 [抖音标识公告](https://trust.douyin.com/article/69831756697378034) |
| 快手 | 用口语写群里催通知和明早交 PPT。把一条能立刻用的核对提醒写进描述，并按上传页准备自定义封面。 [快手上传帮助](https://www.kuaishou.com/help/feedback/4000?categoryId=hot) |
| 小红书 | 用「AI 办公入门」等明确词起标题。把三种任务写成读者可收藏的清单，正文自然写全工具名。 |
| 微信视频号 | 单独准备简洁短标题。描述用普通人听得懂的交付场景讲清用途，话题贴合画面和口播。 |

## 静态封面

- 从成片提取一个短问题、一个可识别角色和至多一行辅助信息。想让别人认出同一系列时，用角色的发型、服饰、标志物与色彩质感维持统一，再按两种比例分别构图。
- 本案横封面为 1920×1080，左标题右人物。竖封面为 1080×1920，上标题下人物。主标题用「这活该找哪个 AI？」，下面一行列出「豆包 · DeepSeek · WorkBuddy」。若用户还需要平台裁切版，按该比例另排或检查裁切后的安全区。
- 出图后先核对汉字、品牌拼写、人物特征和像素尺寸，再缩到约 200 像素宽看主标题和人物是否仍然可辨。预计会被平台裁切时，先模拟裁切，检查大字、眼睛和发夹是否完整。按所需比例分别交付可上传的图片。

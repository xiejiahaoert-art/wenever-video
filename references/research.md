# 表演、剪辑与教学画面的依据

这些资料用来决定镜头怎么安排。论文里的结果有具体实验条件，Vibe 短片采用下列做法属于创作应用。

| 资料与结果 | 对制作的影响 |
| --- | --- |
| Atkinson 等人的点光和全光身体表情实验显示，动作信息能帮助辨识情绪。 [论文](https://doi.org/10.1068/p5096) | 先画四到六个情绪姿态，再做眉眼和嘴。惊讶可用后仰与手停住，焦虑可用缩肩、视线来回和挠头，释然可用肩膀放松和较慢的呼吸。先用剪影静音看，确保动作自己说得通。 |
| Lasseter 描述了预备、缓入缓出、弧线与摆位等动画原则。 [SIGGRAPH 论文](https://users.cs.northwestern.edu/~animation/Lasseter_1987.pdf) | 做接触动作时先锁手的接触点和物件层级。先画预备、接触、反应三帧，再补中间帧。走路有支撑脚，落地有膝盖减震，走停有重心变化。 |
| Magliano 与 Zacks 区分镜头切换和叙事事件边界。Smith 从注意力位置解释视角切换的连续感。 [事件分段研究](https://doi.org/10.1111/j.1551-6709.2011.01202.x) · [注意力与连续性](https://doi.org/10.3167/proj.2012.060102) | 同一件事继续时，保持上一镜的关注物、方向或实际动作。新阶段用色温、环境或距离给观众一个清楚信号。推近用于看结果，拉远用于交代关系，短闪回回答“之前怎样”，硬切可把注意力推到后果。镜头类型跟随叙事需要。 |
| Moreno 与 Mayer 在用动画解释雷电的实验中比较了文字与动画的空间和时间关系。 [论文](https://doi.org/10.1037/0022-0663.91.2.358) | 画面中的“运行失败”“工作区”“远端”等标签贴近对应对象。先用一屏一主句交代判断。数字要有对象或单位，字母要能读懂其作用。示例哈希、伪代码和无含义刻度按需要省掉。 |

对照作品可以先看作者自己的材料。例如 3Blue1Brown 从手写数字识别引出神经网络，再回到同一个图形解释术语。《信息论·惊奇之学》的填空从可预测和难预测的两种体验引出信息概念。使用这些作品时记录它们的进入顺序、图形如何复用和事件如何切换。换成当前内容自己的场所、角色和道具。 [3Blue1Brown 原课](https://www.3blue1brown.com/lessons/neural-networks/) · [《信息论·惊奇之学》原作页](https://www.bilibili.com/video/BV1GXav6iEWh/)

## 逐镜可执行的核对

1. 在分镜里为人物、主字幕、界面与道具各写活动范围。转场从前、中、后抽三帧，检查两层标题不会同时争抢。
2. 检查人物动作起点、目标点、接触帧及结束位置。人物在桌前时桌沿可以遮住手臂的一部分，正文或图解需要让开脸和关键关节。
3. 道具跨镜头传递时给它一个一致的形状，必要时记下安装点、图层顺序和走向。连续截取一个动作而非只看最大张力帧。
4. 看一遍手机大小的画面，再把无用符号删掉。文字与物件同时出现时，给观众足够时间把两者对应起来。

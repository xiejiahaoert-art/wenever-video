# 抖音参考片拆解

这里记录在播放器观察到的画面。时间为取样位置附近的约值。表中的科普用法是为本 Skill 设计的迁移示例。

## 双鱼不吃鱼《首尔今天有点鲁》第 16 集

| 取样范围 | 画面所见 | 可复用的剪法 |
| --- | --- | --- |
| 开头约 0–4 秒 | 门外对话由女性近景切到双人门口构图。她先看向对方，再张开手臂。双人画面让人看清距离和手势指向。 | 用眼神和表情建立意图，然后在更宽的画面里看动作怎样完成或被悬置。开场的问题可以由角色正在做的事提出。 |
| 约 4–8 秒 | 门口景压暗，黑底上出现手写状笔画和线条，随后进入日光下的校内桌边。服装、光线、景别都发生变化。 | 暗场和片名用在真正换段的地方。片名之后先给新的空间和人物关系，观众能辨认进入另一处场景。 |
| 约 8–18 秒 | 桌边先见男生侧眼看向同伴，再给手指到桌面的细节，之后切到男生的表情和举手反应。 | 用「看向哪里 → 细节里发生什么 → 对方怎样反应」组织连续镜头。把手、道具和反应分开安排，每一镜交代一个信息。 |

迁移到科普可把「角色疑惑」演成一次操作。先看向计算结果，再切手指点到统计分母，回到人物抬眼确认。分母随后作为文字图层留在下一镜，继续讲它代表谁。参考片的写实画风与校园素材属于原作，人物和构图按当前项目重新设计。[抖音原片](https://www.douyin.com/video/7711688478257466633)

## 小孔的 Ai 奇异点《Codex 用 Remotion 做的 20 种风格视频》

开头以大数字和色点表明接下来要展示多个样例。样例切换时，说明区和演示框会左右换位，序号、文字层级和顶部进度继续交代当前位置。前后反复出现贡献格子、头像或圆环。约 22 秒的切点附近，先见单独的彩色圆点和新编号，再见放大的手机和贡献格。约 156–159 秒的 2.5D 页面先带入分层界面，再看到时间线有内容。可以借用这种先定位画面，再让细节动起来的节奏。[抖音原片](https://www.douyin.com/video/7698029336707796234)

把样例当作选型。讲系统结构可用等轴堆叠或蓝图分解，讲操作可用 2.5D 推近，讲统计可用固定标尺和条形图。连续科普片可以复用同一字体、字幕区域和提示色，在不同段落改变演示层。若用了粒子、液态或强光效，给落稳后的结果留出读数时间。

# 动画表演与转场

先标清上一镜让观众盯着什么，下一镜要把注意力交给谁。角色表演、换镜和材质特效分别选做法。第一次试片选能完整看到动作和接缝的一小段。

## 人物怎么动

| 节点 | 在分镜中写清 |
| --- | --- |
| 动机 | 谁在等什么、想碰什么、看向谁。用视线、手的预备动作或道具状态露出意图。 |
| 发力 | 标出支撑脚或坐姿支点。身体先给出发力方向，肩肘和手接力。近景可以只动眼神、头或手，搭配自然静止。 |
| 接触 | 手、脚和目标在同一帧对上。切到细节时，接触点、方向和道具状态要延续。 |
| 反应 | 给动作留下结果，人物再看结果、停一下或转向对方。用反应推动下一问。 |

景别跟着信息变化。近景适合眼神与意图，双人中景交代距离和手势，细节镜头交代发生的事，再回反应镜头说清后果。用同侧视线或运动方向接住这组镜头。生成短镜头时，把前一镜的末姿势、人物位置、手中道具和光向写进下一镜；用图层做动作时，保持身体支点和道具接触点可单独调整。

## 怎么从一镜进下一镜

| 剪辑任务 | 可以采用 | 要看清什么 |
| --- | --- | --- |
| 同一动作继续 | 动作途中切景别，保留移动方向和一致的接触位置 | 切点前后手势、速度与结果连得上 |
| 观众需要看清细节 | 先用视线、手指或高亮指出目标，再局部推近。同一个框、圆、颜色或格子可变为下一镜的入口 | 缩放结束后留够时间看目标，回到全貌时还能辨认位置 |
| 换内容但保留上下文 | 固定画幅内的阅读区或进度，把演示层局部替换。需要幅度更大的切换时，先保住一个可认出的轮廓或对象 | 新画风进入后，观众仍知道在讲第几步、比较哪两件事 |
| 真正进入新场景或章节 | 给出空间或时间信号，选择硬切、短暗场或片名卡 | 边界能解释场景变化。连续口播开场可用同一镜头接续，而章节卡适合单独停留的叙事节点 |

把特效和信息变化绑在一起。描线适合路径与因果，依次落位适合步骤与组装，粒子或轮廓变形适合两个对象之间有意义的转换，分层视差适合从全貌到细节。每镜先选能读清的信息和动作，再决定阴影、拖尾、闪光或材质。标题、数字和字幕在动效落稳时保持清楚。

## 逐帧制作与验收

- 一条镜头记录「起止帧、观众焦点、起始动作、接触或变化帧、落稳状态、下一镜锚点、声音落点」。有角色就额外标视线、支点和手中物件。先看变换前、变换中、落稳后的三帧，再以正常速度连播。
- 粒子、光斑和纹理抖动使用固定种子，动画随帧号求值。已有 Remotion 工程可用 `useCurrentFrame()` 读帧号，用 `interpolate()` 的 `clamp` 让进度在端点停稳，用 `spring()` 做需要弹性的落位。`TransitionSeries.Transition` 重叠两个镜头时，总帧数按重叠长度缩短，口播、字幕和拍点要跟着校对。保留切点与时长时，可以用 `TransitionSeries.Overlay` 在切点上叠效果。[帧号](https://www.remotion.dev/docs/use-current-frame) · [插值](https://www.remotion.dev/docs/interpolate) · [弹簧](https://www.remotion.dev/docs/spring) · [镜头重叠与叠加](https://www.remotion.dev/docs/transitions/transitionseries)
- 静音检查「动作意图看得懂、切后知道该看哪里、字幕读得清」。开声核对接触声、旁白与音乐。失误发生在接触点、轴线或画面中断时，优先修镜头连续性。需要分层推镜、纸面动效或其他具体表现时，按 [参考片动效索引](douyin-motion-cases.md) 选合适的一类。

# Xilo 的实操短片案例

用于制作面向初学者的 AI 工具、办公任务或 Skill 教程。这组判断来自「Xilo今天Ai了吗」主页的 21 条公开作品，累计约 85 分钟。取样覆盖开场、主要段落、明显画面变化与片尾。时间供复查，样本没有提供留存或转化数据。[抖音主页](https://www.douyin.com/user/MS4wLjABAAAAhoG2XR5Hx6IfHlJqWxEKYws4afijl98eXChTuyr5OsZULn9vQc-a1Go3aY9gHcNr)

## 设计一条可照做的教程

1. **首屏让结果或问题看得见。** 有成品就给成品和一个可读的细节。有失误就给可同时比较的两种状态。角色的第一个动作交代他在看哪里或为什么卡住。把教程承诺接到这个结果上，工具名在观众有理由关心时进入。
2. **按句子选画面。** 人物场景交代动机和反应，解释图突出一个关系，录屏证明确实发生了哪步操作。录屏优先框出输入、按钮和对应输出。比较修改前后时固定位置和尺度，只突出变化的字段。人物可以从表演退到边缘指引，下一次决策时再回主画面。
3. **先走通，再解释复用。** 用一条素材演出输入、规则与结果。先命名用户已经看懂的动作，再给它装进 Skill。需要教复用时换一条材料，保留规则并改变一个条件，让观众先猜，再看实际结果和验收方法。
4. **让可带走的东西兑现开场。** 可以提前承诺提示模板、清单或结果页。交付时按实际文字长度留出阅读和截图时间，随后用开场对象的变化收束。短片只演完能被验证的一件任务，更多参数可进入配套材料。

## 应用示例

旧书交换会上，PPT 写 A 室，群聊后来改到 B 室。先让两种地点同屏。把原话分为时间、地点、要带什么，再看第二页上的 B 能否追到最后一条明确更正。换成只给了时间的读书会，让地点停在「待确认」。清单给出一页一问、按最新明确更正、缺项留空待确认和逐条核对的做法。

涉及工具能力时根据用户实际可用的界面验证，分别说明文本初稿、排版和文件交付。参考中的截图、收益和工具数据仅用于观察其叙事作用。跨镜怎样承接同一张证据和同一个时间戳，见 [浙大猫学长案例](zjucat-vibe-motion.md)。
